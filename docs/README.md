# Hydroponic Test Simulation - Documentation

This directory contains comprehensive documentation for the Hydroponic Test Simulation system in multiple languages.

## Available Languages

- [English Documentation](./en/README.md)
- [Documentation Française](./fr/README.md)

## Documentation Structure

Each language folder contains:

- **README.md**: Main documentation overview
- **architecture.md**: System architecture and design
- **user-guide.md**: User guide for running and using the simulator
- **api-reference.md**: REST API reference
- **diagrams/**: Architecture diagrams and visual explanations
